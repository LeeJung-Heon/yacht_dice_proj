# 요트 다이스 개인정보처리방침

요트 다이스는 온라인 대전을 위해 기기마다 무작위로 만들어지는 익명 계정 ID와 사용자가 직접 입력한 닉네임, 그리고 한 판의 주사위 눈과 점수 기록만을 Supabase(서울 리전) 서버에 저장한다. 이 정보는 상대와 판을 진행하는 데 쓰이며 광고나 추적에 쓰이지 않는다. 앱을 삭제하면 익명 계정과의 연결이 끊어지며, 서버에 남은 기록은 저장소 문의 채널(GitHub Issues)로 요청하면 지운다. 사운드·햅틱 설정과 닉네임은 기기 안에만 저장된다.

컵퐁의 “나만의 컵” 기능을 사용하면 사용자가 직접 선택한 사진만 읽는다. 사진은 방향을 보정하고 가운데를 512×512로 잘라 위치 등 원본 메타데이터 없이 기기와 Supabase 서버에 저장한다. 사진은 익명 계정 ID에 연결되며 본인과 컵퐁 대전 상대에게 표시된다. 컵별 삭제 버튼으로 사진을 삭제할 수 있고, 온라인 연결 시 서버에도 삭제가 반영된다. 공유가 실패하면 기기에서 변경한 상태를 유지하고 다시 시도할 수 있다. 사진 보관함의 다른 사진에는 접근하지 않는다.
