# 게임 필드·물리 개편

- iOS 18+, Swift 6, SwiftUI/RealityKit. 기존 컵별 사진과 온라인 상대 공유 유지.
- 컵퐁: 속이 빈 성형 플라스틱 컵, 말린 림·하단 리브, 액체 표면, 실제 그림자, 결이 있는 테이블과 은은한 실내광. 공은 테이블·림·컵 벽 충돌에 반응하며 에너지를 잃는다. 예상 궤적은 표시하지 않는다.
- 컵퐁 판정은 240Hz 고정 스텝 정수 시뮬레이션으로 계산하고 화면은 같은 시뮬레이션의 공 위치를 보간해 재생한다. 중력·공기 저항·표면별 반발에 따라 움직이며, 모든 컵에 도달할 수 있고 화면의 공 높이가 충돌 높이와 일치해야 한다. 상대 컵 열 개를 먼저 비우면 승리하고 성공하면 같은 사람이 다시 던진다.
- 알까기: 17줄 판에서 3판 2선승. 1R 기본판, 2R 모서리가 잘린 판, 3R 중앙 범퍼. 모서리는 실제 낙하 영역이고 범퍼는 충돌 시 돌을 반사하며, 해당 장애물과 겹치는 배치는 거부한다. 라운드마다 돌 다섯 개를 다시 배치하고 선공은 흑·백·흑 순서로 교대한다. 온라인에서는 다음 선공인 플레이어만 다음 라운드를 시작할 수 있다. 무승부는 승수·맵·선공을 유지한 채 같은 라운드를 재경기한다.
- 사용자 확인: 실제 영역과 화면 모두 확대. 오목은 19줄, 알까기는 17줄. 화면 좌우 여백을 줄이고 선택·배치 조작을 유지한다.
- 오목은 19×19 교차점에서 금수 없이 다섯 개 이상 이으면 승리하는 기존 규칙을 유지한다. 오목·알까기 화면의 좌우 여백은 4pt로 줄인다.
- 오목·컵퐁·알까기는 기존 게임 ID를 유지하고 `MoveLog`에 `rulesVersion: 2`를 기록한다. 버전이 없거나 1인 기록은 빈 방도 포함해 읽기를 거부한다. 다른 버전의 온라인 판을 열 때는 업데이트 후 새 방 안내를 표시하고, 이어할 수 없는 로컬 저장은 제거한다. 요트 로그는 변경하지 않는다.
- `supabase/migrations/20260922_game_rules_version.sql`은 사용자 확정 후 2026-09-22 운영 DB에 적용했다. `join_match`에 `p_rules_version`(기본값 1)과 `p_game`(기본값 null)을 추가해 행 잠금 안에서 호환성을 확인한 뒤 게스트를 배정한다. 기존 인증·이름·프로필 검증을 유지하고 생성된 방의 규칙 버전 변경은 트리거로 막는다. 배포 전에 마이그레이션을 적용하고 새 버전의 방 생성·참가·턴 왕복 및 구버전 참가 거부를 확인해야 한다.
- 사용자 확정(2026-09-22): 모든 디자인과 규칙을 확정했다. 알까기는 아래의 제한된 조준 안내를 추가하고 검증한 뒤 기존 요청대로 main 병합·서버 마이그레이션·TestFlight 배포를 진행한다.
- 알까기 조준 안내: 당기는 동안 초기 진행 방향만 최대 약 2.5칸·0.2초·전체 이동의 앞 1/3 안에서 보여준다. 돌 충돌·범퍼·낙하 이전에 끊으며, 점선은 끝으로 갈수록 흐려진다. 실제 힘과 승패 판정은 바꾸지 않는다.
